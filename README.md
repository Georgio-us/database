# База объектов недвижимости

Frontend-прототип внутренней базы агентства недвижимости

Система предназначена для общей работы риелторов с объектами, контактами собственников, актуализацией, подборками, импортом и публикациями на OLX и DIM.RIA

## Текущее состояние

- основной frontend-контур готов
- данные внутри интерфейса демонстрационные
- изменения не сохраняются после перезагрузки
- backend, PostgreSQL и авторизация ещё не разработаны
- реальные интеграции OLX, DIM.RIA и НБУ ещё не подключены
- интерфейс сайта агентства и выгрузка на сайт не входят в текущий этап

Актуальное состояние подробно описано в [checkpoint](docs/checkpoint-2026-09-22.md)

## Как открыть прототип

Из корня проекта выполнить

```bash
python3 -m http.server 4173 -d dist
```

После запуска открыть `http://127.0.0.1:4173/`

Также можно открыть `dist/index.html` напрямую, но локальный сервер точнее воспроизводит работу будущего приложения
